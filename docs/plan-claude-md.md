## 4. 승인 필요 — 지시서가 "그대로 이관"이라 한 부분에 저장소 부적합 1건

§7-2는 협업 방식 5단계를 **그대로 이관**하라고 했다. 그런데 원문 4단계에 이런 문장이 있다.

> 4. **기계적 구현** — … `any`/`unknown` 타입을 쓰지 않고, typecheck를 계속 돌려 새 문제를 만들지 않는다.

`any`/`unknown`과 typecheck는 **TypeScript 전제**다. Autoposting은 타입 검사기가 없는 Python 저장소이므로
그대로 옮기면 §3-1이 경계한 것과 같은 종류의 실속 없는 문장이 된다. 아래로 바꾸기를 제안한다.

```
4. **기계적 구현** — 승인 후 전부 구현한다. 작업·단계를 끝낼 때마다 계획 문서에 `[x]` 표시하고,
   모든 항목이 끝날 때까지 멈추지 않는다. 변경할 때마다 아래 «검증»을 돌려 새 문제를 만들지 않는다.
```

  범위를 좁혀 다시 시작하는 쪽이 거의 항상 결과가 좋다.
- 계획서에 **"제외(scope 밖)"** 항목을 적극적으로 써서 diff를 작게 유지한다.
- 건드리면 안 되는 선이 그어지면 그 밖으로 나가지 않는다.

## 이 저장소에서 특히 조심할 것

전부 「동작은 하는데 조용히 틀리는」 종류다.

- **`data/phrases.json`의 모든 항목이 `Phrase` 스키마와 정확히 일치해야 한다.**
  `storage.py`가 `Phrase(**item)`로 통째로 넘기므로, 키가 하나라도 빠지거나 남으면
  `TypeError`로 **게시 전체가 죽는다**. 필드를 추가하면 45건 전부를 같은 커밋에서 채운다.
- **중복 방지는 `is_published` 하나로만 한다.** 전부 소진되면 `reset_all`로 자동 순환한다.
  이 동작을 임의로 바꾸지 않는다.
- **X의 글자수는 `len()`이 아니다.** 한글·가나·한자는 1자가 **2**로, URL은 길이와 무관하게
  **23**으로 계산된다(weighted length). `content.py`의 `MAX_LENGTH=280` 비교는 `len()` 기준이라
  실제보다 **약 40% 적게** 센다. 실측: 현행 템플릿 45건 중 **43건이 이미 280 초과**이고,
  그중 하나(id=40, weighted 298)가 실제로 게시에 성공했다 — 즉 이 계정의 실제 상한은 280이 아니다.
  길이를 논할 때 `len()` 값을 근거로 쓰지 말 것.
- **API 키·토큰은 `.env`(및 GitHub Secrets)로만.** 코드 하드코딩 금지.
  예외는 비밀이 아닌 공개 URL(`LINE_ADD_URL`)의 기본값뿐이다.
- **`HOMEPAGE_URL`이 비면 `https://example.com`이 그대로 게시된다.** `config.py`의 기본값이라
  아무 에러 없이 조용히 나간다. Actions Secrets에서 지우지 말 것.
- **새 플랫폼 추가는 `platforms/base.py` 상속 + `platforms/__init__.py`의
  `get_enabled_posters()` 등록**만으로. `job.py`는 수정 불필요.
- **워크플로가 매 실행마다 `main`에 커밋한다.** 파일/페이지를 추가하면 `README.md`·
  `.env.example`·`.github/workflows/hourly_post.yml`의 정합성을 같은 커밋에서 맞춘다.

## 7. 트레이드오프

- **karpathy 4원칙을 한국어로 요약해 흡수했다.** 원문은 영어 전문(69줄)이다. 통합본이 한국어이므로
  언어를 통일했고, 그 과정에서 예시 일부가 축약됐다. 원문 영어 전문을 그대로 넣기를 원하시면 그렇게 한다.
- **"조심할 것"을 7개로 늘렸다.** 지시서 §7-3의 6개에 `HOMEPAGE_URL` 항목을 더했다.
  이번 검증에서 실제로 발생했던 사고(빈 값이면 `example.com`이 게시됨)라 같은 종류에 해당한다고 판단했다.
- **검증 명령에 `encoding='utf-8'`을 명시했다.** 지시서 §7-4 원안에는 없다.
  Windows 로컬에서 기본 인코딩이 UTF-8이 아닐 때 깨지므로 이식성을 위해 넣었다.
- **검증 3번(`run_once.py`)은 네트워크를 탄다.** 인증 정보가 없으면 게시가 실패하지만
  "예외 없이 완주"는 확인된다. 완전 오프라인 검증만 원하시면 3번을 뺀다.
